# রক্তদাতা ম্যাচিং অ্যাপ (বাংলাদেশ)

জরুরি রক্তের অনুরোধ কাছাকাছি, যোগ্য ও যাচাই করা রক্তদাতাদের কাছে ধাপে ধাপে (wave) পৌঁছে দেওয়ার Android অ্যাপ। প্রথম লঞ্চ: রাঙামাটি। পুরো সিস্টেম ফ্রি-টিয়ারে চলে।

- `app/` — Flutter অ্যাপ
- `supabase/` — মাইগ্রেশন, Edge Functions, টেস্ট
- `docs/` — পরিকল্পনা ও সিদ্ধান্ত
  - [STATUS.md](docs/STATUS.md) — এখন কোন কাজ চলছে
  - [PRD.md](docs/PRD.md) — প্রোডাক্টের চাহিদা ও সিদ্ধান্ত
  - [MVP.md](docs/MVP.md) — আর্কিটেকচার, স্কিমা, স্প্রিন্ট পরিকল্পনা
  - [decisions/](docs/decisions/) — ADR
  - [sprints/](docs/sprints/) — স্প্রিন্টের কাজের তালিকা
